# 🏨 Hotel Reservation Cancellation Prediction

## Project Overview
This project predicts whether a hotel reservation is likely to be cancelled before check-in using Machine Learning techniques.

## Business Problem
Hotel cancellations impact revenue, occupancy planning, and resource allocation. Early prediction helps improve decision-making and operational efficiency.
